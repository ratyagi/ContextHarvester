Context Harvester

Ranked minimal file set a coding agent needs to read to fix an issue. File-level recall against the files the merged fix touched.

Read this first. Recall against changed files is a lower bound on the true target. An agent must read more than it edits, so a highly ranked file that is absent from the gold set is not necessarily a false positive. Sources are never pooled: SWE-bench Verified is likely over-represented in model training data, so the self-harvested set is the control.
